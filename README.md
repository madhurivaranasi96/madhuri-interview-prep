# Interview OS — Senior Engineer Preparation

A polished Angular-based interview preparation workspace covering C#, .NET, Angular, JavaScript, SQL, system design, AI/Agentic AI and production debugging.

## Run locally
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

The app uses hash routing so it can be hosted on GitHub Pages without server-side route configuration.

## Roadmap
Foundation → Intermediate → Advanced → Senior → Expert

The UI is intentionally data-driven so question banks, progress tracking, bookmarks, mock interviews, coding exercises, practical tasks and cheat sheets can be expanded without changing the core architecture.
